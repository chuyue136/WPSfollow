# v0.1.2 测试版

核心修复版：重点解决"墨迹与页面越滚越偏"和"到页顶/页底墨迹甩出去回不来"两大类问题。
这一版在高 dpi 大屏（希沃八代 288dpi）和本机 96dpi 上实测均有明显改善。

## 这一版改了什么

- **高 dpi 屏（希沃八代）上墨迹与页面彻底脱节**
  原因是物理像素与 DIP 混用：抓帧拿到的是物理像素（3840×2040），墨迹 API 用的是 DIP，288dpi 下差 3 倍。
  代码里五处把物理 px 当 DIP、三处把 DIP 当物理 px，推墨迹、补差、撤回、对账阈值全都偏 3 倍，
  而且对账拿墨迹自己当页面测量，错的量出来正好"自洽"，于是一直报"一致"。
  → 现在统一单位铁律：抓帧/匹配/账本一律物理像素，墨迹一律 DIP，换算收进唯一出口；
  每拍校验 dpi，变了就作废账本重新标定；阈值/上限按窗口高算，不再写死。

- **docx 上墨迹与页面完全错位**（三个原因叠加）
  1. 每格实际是 84px 左右，代码按 60px 起步，且多格批量从不采信测量，每格越差越多；
  2. WPS docx 不认 `delta` 大小，一条滚轮消息无论 delta 多大都只滚一格，原来 6 格合成一条发 → 页面滚 1 格、墨迹推 6 格；
  3. 连按时 6 格位移超过窗口高度，锚点帧与当前帧毫无重叠，对账永远"测不出"。
  → 现在一格一条滚轮消息、间隔 260ms；**一拍一结算**：按键前留一帧，发完等画面静止，
  量出这一拍真滚了多远，按实测值摆放墨迹，再把锚点挪到这一拍之后。连按多少下都在可测范围内。

- **到页顶/页底连按，墨迹一路甩出去且回不来**
  原来按"格数 × 每格"的模型值摆放墨迹，模型不知道页面已经到边。
  → 改成测量优先：页面没动（整帧几乎相同）就判 0，墨迹原地不动；实测页顶连按 21 拍位移不再增长。

- **每格像素改为显式标定**：只在独立测量出真实位移后定值，不再靠猜；心跳日志会显示"已标定/未标定"。

- **稳定性**：抓帧全局串行（避免两个线程同时 `PrintWindow` 卡住 WPS 界面），结算放后台线程，不冻 UI。

## 安装

1. 下载 `WpsInkSync.icpx`（约 39 KB）。
2. 丢进 ICC CE 的插件目录：`<ICC 安装目录>\Plugins\com.yg.wpsinksync\`（目录名必须等于 `com.yg.wpsinksync`）。
   也可以解压后把 4 个文件放进去：`manifest.json` / `WpsInkSync.dll` / `WpsInkSync.deps.json` / `WpsInkSync.runtimeconfig.json`。
3. 重启 ICC CE。

要求：ICC CE ≥ `1.8.0.0`，.NET 10 桌面运行时（ICC 自带）。

## 功能

- 浮动栏按钮 `跟随` / `上1` / `下1` / `上6` / `下6`，上图标下文字，和原生 `鼠标/批注/白板` 同观感；跟随关掉时整排翻页按钮收起。
- 热键 `Ctrl+Alt+↑↓`、`+PgUp/PgDn`、`Ctrl+Alt+F` 跟随开关、`Ctrl+Alt+R` 归位、`Ctrl+Alt+K` 打样、`Ctrl+Alt+M` 打标记、`Ctrl+Alt+D` 调试控件。
- 设置页（设置 → 插件设置 → WPS 墨迹同步 设置）：显示插件按钮（始终 / 仅当 WPS 运行时 / 关闭）、是否显示 6 行滚动按钮、显示调试控件、打开日志目录、复制今日日志、内联看日志。
- 选 `关闭` 时整块插件停止运行（不抓帧、注销热键），工具栏连底壳一起收起。
- 支持 WPS PDF 与 .docx；每格像素显式标定（PDF 300% ≈ 60px、docx 200% ≈ 86px）。
- 只跟我们自己发的翻页；鼠标滚轮 / 手型拖动 / 拖滚动条一律不动笔迹。
- 浅色/深色主题自动切换前景色。

## 已知边界

- **首次打开 WPS 文档后第一次下滚，docx 可能差一行**（已知问题，正在定位；出现后按一次反向键或 `Ctrl+Alt+R` 归位）。
- 到文档首/尾时按钮会"空按"（墨迹先动再撤回，约 0.5s 抖动），最终位置一定对齐。
- 一批连按超过半屏时仍无法逐格复核，只能信命令；WPS 少吃/多吃几格可能偏几行。
- 改缩放后每格像素变了：`stepPx` 会重新标定，但缩放那一下墨迹不跟着缩放。
- 单格偶尔被 WPS 吃掉：靠结算和对账补；都测不出时最多差一格，按一次反向键或归位可修。
