# v0.1.0 测试版

首个可用的测试版。ICC CE 浮动工具栏加一排翻页按钮：按一下让 WPS 滚 N 格，画布上的批注笔迹按同样像素平移。

## 安装

1. 下载 `WpsInkSync.icpx`（35 KB）。
2. 丢进 ICC CE 的插件目录：`<ICC 安装目录>\Plugins\com.yg.wpsinksync\`（目录名必须等于 `com.yg.wpsinksync`）。
   也可以解压后把 4 个文件放进去：`manifest.json` / `WpsInkSync.dll` / `WpsInkSync.deps.json` / `WpsInkSync.runtimeconfig.json`。
3. 重启 ICC CE。

要求：ICC CE ≥ `1.8.0.0`，.NET 10 桌面运行时（ICC 自带）。

## 功能

- 浮动栏按钮 `跟随` / `上1` / `下1` / `上6` / `下6`，上图标下文字，和原生 `鼠标/批注/白板` 同观感。
- 热键 `Ctrl+Alt+↑↓`、`+PgUp/PgDn`、`Ctrl+Alt+F` 跟随开关、`Ctrl+Alt+R` 归位、`Ctrl+Alt+K` 打样、`Ctrl+Alt+M` 打标记、`Ctrl+Alt+D` 调试控件。
- 设置页（设置 → 插件设置 → WPS 墨迹同步 设置）：显示插件按钮（始终 / 仅当 WPS 运行时 / 关闭）、是否显示 6 行滚动按钮、显示调试控件、打开日志目录、复制今日日志、内联看日志。
- 选 `关闭` 时整块插件停止运行（不抓帧、注销热键），工具栏连底壳一起收起。
- 支持 WPS PDF 与 .docx；每格像素自学习（PDF 300% ≈ 60px、docx 200% ≈ 87px）。

## 精度（本机实测）

单格 10 上下往返、6 格 2 上下往返、到顶/到顶连按 2/3/5/8 下，截图逐点差全部 **0%**（残留仅重排抗锯齿）。明细见 [CHANGELOG](https://github.com/chuyue136/WPSfollow/blob/main/CHANGELOG.md#实测记录)。

## 已知边界

- 单格偶尔被 WPS 吃掉：靠收尾"对账"补；三次都测不出时最多永久差一格，按一次反向键或 `Ctrl+Alt+R` 归位。
- 一批连按 > ~10 格（600px）无法复核，只能信命令，WPS 少吃/多吃几格会偏几行。
- 到文档首/尾时按钮会"空按"（墨迹先动再撤回，约 0.5s 抖动），最终位置一定对齐。
- 改缩放后每格像素变了：`stepPx` 会自学习回来，但缩放那一下墨迹不跟着缩放。
- 只跟我们自己发的滚动；鼠标滚轮 / 手型拖动 / 拖滚动条一律不动笔迹。
