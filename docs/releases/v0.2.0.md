# v0.2.0 测试版（里程碑）

这一版把 WPS 联动从“截图猜页面有没有滚动”彻底改成读取 WPS 自己的位置/滚动值，docx 和 PDF 都不再依赖图像匹配。

## 主要变化

- **docx**：继续用 WPS COM 的正文 `GetPoint` 竖直坐标做标尺；ICC 的 UIAccess 进程里通过 IDispatch 晚绑定读取。
- **PDF**：新增 UIA 滚动条标尺（`KPdfScrollBarWheelFixed` 的 `RangeValuePattern`），读数与屏幕物理像素 1:1。
  发送前记锚点，每格等数值真正变化再发下一格，发完只补这一拍的差。
- **逐拍结算**：每次按键只结算自己这一拍，到边时只撤回这一拍的乐观平移，不再整批回滚。
- **性能**：单格不再固定等几百毫秒；6 格按页面实际动画自适应发送。

## 实测

- 本机 docx：冷启动 6 格 504px / 约 830ms；单格 84px；打样目视对齐。
- 本机 PDF 125%：单格 5 下 5 上回到 `Δ=0`；6 格多次上下精确回到 0；页首/页尾实测 0px 不漂。
- 本机 PDF 6 格发送约 0.38–0.45s，整拍约 0.9s。
- 希沃八代 288dpi：待复测。

## 已知边界

- 只有 WPS 的 docx / PDF 会跟随；外部鼠标滚轮、手型拖动、滚动条拖动仍然不跟。
- 老版本 WPS 的 PDF 如果没有 UIA 滚动条，会自动回退截图逐拍路径，精度和速度略低。
